# Segurança

O APEX foi projetado para execução local em `127.0.0.1`. Não exponha o servidor diretamente à internet: esta versão não possui autenticação, autorização multiusuário, proteção CSRF, HTTPS ou rate limiting.

Não publique API keys, tokens, cookies, senhas ou bancos de dados locais. Para relatar um problema de segurança, abra uma issue privada no GitHub quando o repositório oferecer essa opção ou entre em contato com os mantenedores por um canal privado.
